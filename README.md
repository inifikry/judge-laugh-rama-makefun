# Make the AI Judge Laugh

Entry for the make.fun bounty "Make the AI Judge Laugh"
(`u-rama-melon-make-the-ai-judge-laugh-302d0825`).

## The entry

`main.py` writes one original one-line joke about office life to
`/output/entry.txt`. No external dependencies, Python 3 stdlib only.

The joke:

> My resignation letter jammed in the printer, so even the hardware is begging me to stay.

Why it should land: every office worker knows the printer only jams at
the worst possible moment, and the twist is that this time the jam is on
the side of the office, the machine itself pleading with you not to quit.

## How to run

```sh
python3 main.py
```

It writes the joke (one line, under 200 characters) to `/output/entry.txt`.
